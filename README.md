# Polaroid | Interactive Photography Web Application

Polaroid is an interactive, browser-based photography application that recreates the experience of capturing, developing, organizing, and displaying photographs through a nostalgic Polaroid-inspired interface.

Built using HTML5, CSS3, and JavaScript, the application combines responsive web design, interactive animations, and client-side functionality to create an engaging photography experience.

## Live Demo

**Website:** https://praishwarya10.github.io/polaroid-web-app/

**GitHub Repository:** https://github.com/praishwarya10/polaroid-web-app

## Features

### 1. Home
- Polaroid-inspired landing page with an interactive interface.
- Navigation across the application's photography features.

### 2. Camera
- Image upload and interactive photo framing.
- Drag-to-position functionality for adjusting photographs.

### 3. Photobooth
- Three-shot photography experience.
- Camera flash effects and animated interactions.
- Polaroid-style photo presentation.

### 4. Darkroom
- Interactive photo development experience.
- Visual transitions and development animations.

### 5. Shoebox
- Virtual collection for organizing photographs.
- Interactive photo browsing and flip animations.

### 6. Wall
- Digital photo display inspired by a physical photo wall.
- Drag-and-drop interactions for arranging photographs.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/praishwarya10/polaroid-web-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd polaroid-web-app
   ```

3. Open `index.html` in a modern web browser.

No additional dependencies or installation steps are required.
